# Google Form ファイルリネーマー

Google フォームにはファイルアップロードができる便利な機能があります。しかし、フォームでファイルをアップロードしたとき、そのファイル名は、送信者のつけたファイル名に基づいたものになります。スプレッドシートとの紐づけが行われますが、ファイル名の不統一があると、ファイルの中身を見るまでどの（誰の）書類かわからない、ソートできないなど、ファイル回収側としては、極めて不便です。できれば、統一した命名規則でファイルを収集・保存したいところです。

Google フォームにアップロードされたファイルを、回答内容に基づいて自動リネームする Google Apps Script アドオンです。
フォームの入力項目に基づいてアップロードされたファイルの自動リネームが行えます。フォルダ分け（仕訳）を自動的に行う機能も有しています。

## 機能

- **サイドバー GUI** でコード編集なしに設定を変更
- **ファイル名の構成** をドラッグ＆ドロップで並べ替え
- 各項目に **接頭辞・接尾辞** を付加可能
- **区切り文字** を自由に設定（デフォルト `_`）
- **拡張子の自動小文字化**（`.JPEG` → `.jpeg`、`.PNG` → `.png` など）
- **拡張子の変換ルール**（例: `.jpeg` → `.jpg`）
- **複数ファイル対応**: 1 回答に複数ファイルがある場合、連番（`_01`, `_02`…）を自動付与
- **サブフォルダ自動仕訳**: 選択した項目の回答値をフォルダ名として、アップロード先にサブフォルダを作成しファイルを自動で移動
- **プレビュー機能** で保存前にファイル名のイメージを確認
- 設定は `PropertiesService` に永続化

## ファイル構成

| ファイル | 説明 |
|---|---|
| `Code.gs` | メインスクリプト（トリガー処理・設定管理・リネーム処理） |
| `Sidebar.html` | 設定用サイドバー GUI |
| `appsscript.json` | マニフェスト（スコープ・ランタイム設定） |

## セットアップ

> 組織内アドオンとしてデプロイ・利用する場合は [ADDON_GUIDE.md](ADDON_GUIDE.md) を参照してください。
> 以下はバウンドスクリプト（個別のフォームに直接貼り付けて使う）方式の手順です。

1. Google フォームを開き、メニュー `⋮` →「スクリプト エディタ」を開く
2. プロジェクト名を「ファイルリネーム設定」など分かりやすい名前に変更する（この名前がフォームのアドオンメニュー名として表示されます）
3. `Code.gs` の内容をエディタに貼り付ける
4. `Sidebar.html` をファイルとして追加する（エディタ左パネル「＋」→「HTML」→ ファイル名を `Sidebar` にして内容を貼り付け）
5. フォームを開き直すと、手順 2 で付けた名前のメニューが表示される
6. メニューの「トリガー無効 → 有効化」でフォーム送信時のトリガーを登録する
7. メニューの「設定を開く」からサイドバーで各項目を設定する

## 設定項目

| 設定 | 説明 |
|---|---|
| ファイルアップロード項目 | フォーム内のどの項目がファイルアップロードか選択 |
| 区切り文字 | ファイル名の各部分をつなぐ文字（デフォルト `_`） |
| ファイル名の構成 | 使用する項目とその順序を設定。各項目に接頭辞・接尾辞を追加可能 |
| サブフォルダ | 選択した項目の回答値をサブフォルダ名として、ファイルをそのフォルダへ移動（「使用しない」も選択可） |
| 拡張子の変換ルール | 拡張子のカスタム変換を定義（デフォルト: `.jpeg` → `.jpg`） |
